# Changelog

All notable changes to this SDK are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-10-10

- Relicensed public surface under Elastic License 2.0 (ELv2).
- Raised Go module requirement from 1.21 to 1.23; CI matrix now covers Go 1.23 / 1.26 / 1.27.
- Added Dependabot configuration for Go modules and GitHub Actions.

## [1.0.0] - 2026-04-06

- Initial public SDK surface with repository documentation kit.
